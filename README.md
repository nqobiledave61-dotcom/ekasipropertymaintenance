## 📖 Project Overview
This project involves designing and developing a responsive website for **Ekasi Property Maintenance (EPM)**, a small business specializing in handyman services, lawn care, plumbing, and home renovations. The website will serve as a professional portfolio, improve customer engagement, and provide an online platform for requesting quotes.

## 🎯 Website Goals and Objectives
- Establish a strong online presence for EPM  
- Showcase completed projects through a gallery  
- Provide a simple, user-friendly interface accessible to all age groups  
- Enable customers to request quotes directly online  
- Build credibility with banks, investors, and homeowners’ associations  

Ekasi Property Maintenance Website
📖 Project Overview
This project is a responsive website for Ekasi Property Maintenance, a trusted property services provider in Soweto. The site showcases services, a gallery, contact information, and a quote request form. It is built with HTML5 and CSS3, following best practices for layout, typography, and responsive design.

🎯 Learning Outcomes
External stylesheet linked across all pages.

Typography styles applied consistently for readability.

Layout structure using responsive spacing and shadow borders.

Decoration and color with a modern blue + grey theme.

Pseudo-classes for interactive hover effects.

Responsive design using media queries, relative units, and responsive images.

🛠️ Technologies Used
HTML5

CSS3 (external stylesheet)

GitHub for version control and documentation

📱 Responsive Design
Breakpoints: Desktop (≥1024px), Tablet (768px), Mobile (≤480px).

Relative units: Used em, rem, and % for scalable fonts and layouts.

Responsive images: Implemented srcset and sizes attributes for optimized loading.
