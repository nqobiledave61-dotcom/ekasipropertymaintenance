# Ekasi Property Maintenance Website

## Overview
This project is part of **Web Development (Introduction) – WEDE5020**.  
It demonstrates the use of **HTML, CSS, and JavaScript** to build a responsive, interactive, and SEO‑optimized property maintenance website.

---

## Learning Outcomes
- Implement JavaScript functionality (search filter, gallery lightbox, interactive map, form validation).
- Apply SEO best practices (meta tags, alt text, sitemap, robots.txt).
- Create and validate forms with HTML and JavaScript.
- Deploy the website on a free hosting platform (Netlify/GitHub Pages).
- Maintain a GitHub repository with descriptive commits and a detailed changelog.
